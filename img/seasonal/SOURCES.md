# Halloween game artwork

Kingshot game artwork, retrieved 28 October 2026 from the public Kingshot Packs calculator. Used as small event and reward identifiers. Files are served locally and, except the reconstructed icons below, unchanged; no generated artwork is included.

The source serves eleven item icons as bag tiles: the game's coloured tile with a count printed on it (`charm-material`, `epic-conquest`, `epic-expedition`, `gear-material`, `gold-key`, `hero-xp`, `lucky-gear`, `mythic-conquest`, `mythic-expedition`, `vip-xp`, `vip-1000`). No clean versions were found at Kingshot Packs, Kingshot Optimizer or Kingshot Guide, so these files are reconstructed from the source tiles by `.dsh/seasonal-icon-cutout.py`. It fits the tile's background, cuts the item out, lifts the printed count and repaints what the count covered. The Hero XP "5K" plate is removed with it. The two mythic books came from a very small tile and keep a soft patch where their count sat. VIP XP keeps its "100"/"1K" denomination, which is part of the item's art.
