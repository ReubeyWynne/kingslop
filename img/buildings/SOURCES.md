# Building artwork — provenance

Original Kingshot game artwork, published by Century Games and served by the
Kingshot Optimizer community tool. Retrieved 17 October 2026 from the building
icons its Buildings pages reference: https://kingshotoptimizer.com/.
No generated raster artwork is included.

| Local files | Source URLs |
| --- | --- |
| `town-center.webp`, `embassy.webp`, `barracks.webp`, `range.webp`, `stable.webp`, `command-center.webp`, `infirmary.webp`, `war-academy.webp`, `academy.webp` | `https://kingshotoptimizer.com/images/icons/buildings/{name}.png` |

The 256-pixel PNG files were scaled to 128 pixels and saved as WebP. Assets are
served from this repository, without runtime hotlinks.
